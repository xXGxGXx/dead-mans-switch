# Dead Man's Switch — Gumroad Landing Page Draft

## Headline
Your automation died quietly. Now you'll know in seconds.

## Subheadline
A heartbeat-based liveness monitor for any scheduled automation — Grok, Zapier, Make, cron, GitHub Actions. One line of code. Instant alerts when silence hits.

## The Problem
Scheduled automations fail silently. You find out three weeks later when a client complains or a deposit never lands. By then the damage is done.

## The Solution
Dead Man's Switch is a universal heartbeat monitor. Your automation emits one line on a schedule. If that line stops, you get an instant app-only alert — classified as either the monitor itself dying or the component it watches.

## Key Features
- **Universal emitter contract** — one line works with any stack
- **Dual-surface proof** — Drive heartbeat file plus GitHub commit, so a single surface failure can't fake a healthy system
- **Instant alerts** — app-only notification the moment silence is detected, no polling delay
- **Self-monitoring** — distinguishes monitor-dead from component-dead so you fix the right thing
- **Zero ongoing config** — set it once, forget it

## Who It's For
Solopreneurs, indie builders, and anyone running scheduled jobs who can't afford silent failures. Not for enterprises with dedicated ops teams — for the one-person shop where you are the ops team.
